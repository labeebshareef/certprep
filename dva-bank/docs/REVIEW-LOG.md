  - `messaging/0004` — `MaximumMessageSize` now defaults to 1 MiB (not 256 KiB); explanation rewritten.
  - `messaging/0008` — ambiguous distractor (a `States.ALL` catcher) made unambiguous by tightening the stem; explanation corrected (retriers run before catchers).
  - `messaging/0009` — `HeartbeatSeconds` only times out if the external app sends heartbeats; recommend `TimeoutSeconds`.
  - `iam-cognito/0002` — JS SDK v3 skips env-var credentials when `AWS_PROFILE` is set, unlike boto3; explanation no longer depends on chain order.
  - `iam-cognito/0005` — added the 1-hour role-chaining cap, which applies to the scenario.
  - `iac-apigw-containers/0003` — CloudFormation Export/ImportValue blocks deletion/replacement, not in-place edits; stem tightened.
  - `iac-apigw-containers/0007` — API Gateway integration timeout can be raised above 29 s for Regional/private REST APIs (2024); item no longer implies a hard ceiling.
  - `iac-apigw-containers/0010` — no task role on Fargate → missing credentials, not AccessDenied.
  - `observability/0011` — `Cache-Control: max-age=0` is cache invalidation, not bypass.
  - `lambda/0002` — removed an unsupported "AWS recommends destinations over DLQ" attribution; kept the factual reason.
  - `dynamodb/0004` — added the on-demand "double previous peak within 30 minutes" caveat so the item doesn't teach that on-demand never throttles.
